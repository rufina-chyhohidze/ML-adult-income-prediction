### Problem Statement

The goal of this project is to **predict whether an individual’s annual income exceeds $50,000** based on demographic and employment-related attributes collected from the 1994 U.S. Census database. This is a **binary classification problem**, where the target variable `income` has two possible classes:

* `<=50K`
* `>50K`

By building a predictive model, we aim to analyze which demographic and work-related factors (e.g., age, education, occupation, marital status, hours worked per week, capital gain/loss) are most influential in determining income level.

---

### Why this matters (context you can add for justification)

* This type of problem has **real-world applications** in understanding socioeconomic factors that affect income inequality.
* Businesses and policymakers may use similar models to study labor markets, detect biases, or tailor services.
* For ML purposes, this dataset provides a **rich mix of categorical and numerical features**, making it ideal to showcase preprocessing, feature engineering, and different classification models.
